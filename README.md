# OS 期中練習（NTHU CS3423, Fall 2026）

兩回練習，每回 200 題，範圍 Week 2–6（W2 45、W3 45、W4 35、W5 45、W6 30 題）。

- **`os-midterm-practice.html`（第一回）**：Quiz 1–4 的原題改寫 + 變化題。
- **`os-midterm-practice-2.html`（第二回）**：200 題全新的變化題，不和第一回重複。

兩個都是單一檔案、不需要網路，下載後雙擊打開即可作答。網頁功能：送出後立刻顯示對錯、正確答案與詳解；只看答錯 / 曾經答錯的篩選；**重做錯題**（一鍵把答錯的題目全部解鎖重新作答，或在單題按「重做這題」，重做答對的會標成「已訂正」）；作答紀錄存在瀏覽器。

其他檔案：

- `OS期中題庫.md`：Quiz 1–4 原題、答案與解析（第一回的出題來源）。
- `REVIEW.md`：答案疑慮與題目改寫說明。
- `src/`：題目資料（第一回 `w2.js` … `w6.js`、第二回 `set2/`）與產生網頁的腳本，`node src/build.js` 會重新產生兩個 HTML。
- `verify/`：驗證程式（gcc 實測 C 程式輸出、重算計算題、瀏覽器作答測試），見 `verify/README.md`。
