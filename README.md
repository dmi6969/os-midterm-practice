# OS 期中練習（NTHU CS3423, Fall 2026）

200 題作業系統期中考練習題，範圍 Week 2–6（Quiz 1–4 原題與變化題，加上 W6 CPU scheduling）。

- **`os-midterm-practice.html`**：練習網頁，單一檔案、不需要網路，下載後雙擊打開即可作答。
- `OS期中題庫.md`：Quiz 1–4 原題、答案與解析（出題來源）。
- `REVIEW.md`：答案疑慮與題目改寫說明。
- `src/`：題目資料（`w2.js` … `w6.js`）與產生網頁的腳本，`node src/build.js` 重新產生 HTML。
- `verify/`：驗證程式（gcc 實測 C 程式輸出、重算計算題、瀏覽器作答測試），見 `verify/README.md`。
